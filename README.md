# Playwright Playground

A single static page packed with common UI elements — forms, modals, tabs,
accordions, drag-and-drop, tables, delayed/async content, fake auth state,
and a real API call — built as a personal sandbox for learning and testing
[Playwright](https://playwright.dev/).

No build step: plain HTML/CSS/JS. Every interactive element has a stable
`data-testid` attribute for reliable Playwright selectors.

## Running locally

Open `index.html` directly in a browser, or serve it with any static server:

```
npx serve .
```

## Live site

Hosted via GitHub Pages once deployed.
